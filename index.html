⚙ Google Maps setup

GitHub Pages hosts the website. Google Maps supplies the live location suggestions and road distances. To activate those, use your own Google Maps Platform browser API key (billing account and applicable usage charges may be required).

Stored only in this browser, not written into the GitHub file. Restrict the key to your GitHub Pages website and the Google Maps JavaScript API / Places services in Google Cloud.

Enable Maps JavaScript API, Places API (New) and any required directions service for the key. The Google Maps JavaScript Directions service may be subject to legacy access restrictions for new projects. If routing cannot be enabled, use the manual backup.

Road distance is estimated using community mapping services. Check the route against Google Maps before invoicing. Public services may be temporarily unavailable. Jobs are saved only in this browser. Your home address is not published in this file; enter it once and it will be remembered on this device.
